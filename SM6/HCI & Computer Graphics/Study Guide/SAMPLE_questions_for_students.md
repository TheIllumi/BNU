# Sample MCQs for Students

---

## Section 1: Visual Design Principles

**Q1. Which visual design principle is used to make a specific element stand out from the rest of the design?**

- A. Unity
- B. Hierarchy
- C. Emphasis
- D. Scale

**Correct Answer: C**

---

**Q2. Visual hierarchy in UX design is primarily used to:**

- A. Make all elements look equal in importance
- B. Guide users through content in an intentional order
- C. Add decorative variety to the interface
- D. Reduce the number of colors on a page

**Correct Answer: B**

---

**Q12. Which Gestalt principle explains why users perceive a dashed line as a single continuous path rather than separate dashes?**

- A. Proximity
- B. Similarity
- C. Continuation
- D. Closure

**Correct Answer: C**

---

**Q13. A designer uses varied card sizes, colors, and typography across a dashboard to add visual interest. A reviewer says it feels chaotic. Which principle best explains the reviewer's concern?**

- A. Too much emphasis on individual cards
- B. Variety without sufficient unity disrupts cohesion
- C. Scale is inconsistently applied across cards
- D. Gestalt proximity is violated by card spacing

**Correct Answer: B**

---

**Q24. Which of the following best explains why wireframes intentionally omit colour, images, and visual styling?**

- A. Wireframes are intended for developer handoff, and colour adds unnecessary file size
- B. Removing visual details forces stakeholders to focus on structure and information architecture rather than aesthetic preferences
- C. Colour and imagery are added automatically by prototyping tools later in the process
- D. Wireframes are only used internally and do not need to look polished for external review

**Correct Answer: B**

---

**Q30. A designer is mid-way through the design process and needs to communicate to developers how product screens connect and what happens after each user action. Which artefact is best suited?**

- A. A big picture storyboard, because it maps the full user journey from start to finish
- B. A close-up storyboard, because it demonstrates the user flow within the product and how each action leads to the next screen
- C. An empathy map, because it captures what users think and feel at each stage
- D. A goal statement, because it defines the product's intended outcome for the user

**Correct Answer: B**
