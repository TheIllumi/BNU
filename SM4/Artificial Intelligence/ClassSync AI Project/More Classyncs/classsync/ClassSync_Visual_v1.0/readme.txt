ClassSync Visual - ReadMe
=========================

About
-----
ClassSync Visual is an intelligent timetable processing and visualization tool.
It takes CSV files generated by ClassSync and converts them into professional
Excel timetables with analytics and conflict detection.

Quick Start
-----------
1. Download "ClassSync_Visual.exe"
2. Double-click to run (no installation required)
3. Start converting your ClassSync CSV files

CSV File Format
---------------
Your CSV files must include these columns:
- Course_Name
- Instructor
- Section
- Program
- Weekday
- Start_Time
- End_Time
- Room

Usage Guide
-----------
1. Launch the application:
   - Run "ClassSync_Visual.exe"

2. Process Files:
   - Drag & Drop CSV files into the window (or use the Browse button)
   - Choose an output folder (optional)
   - Click "Generate Timetables"
   - View results with analytics and conflict detection

3. Customize Settings:
   - Open the Settings window (gear icon)
   - Configure time slots and duration
   - Adjust colors and fonts
   - Select export and analytics preferences

Troubleshooting
---------------
Common Issues:

1) "Application does not start"
   - Ensure you have Windows 10 or later
   - Make sure you downloaded the complete package

2) "Drag & Drop not working"
   - Use the "Browse" button instead

3) "Output file not created"
   - Check that your CSV is in the correct format
   - Verify that required columns are present
