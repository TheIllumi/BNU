ClassSync v1.0
==============

Intelligent Scheduling & Resource Optimization


ABOUT
-----
ClassSync helps organizations create optimized schedules for classes,
resources, or personnel using advanced genetic algorithms.

The program includes sample datasets (Courses and Rooms) in the "sample"
folder. These demonstrate correct data formatting. When entering your
own data, make sure spelling and formatting are perfect or errors may occur.


SYSTEM REQUIREMENTS
-------------------
- Windows 7/8/10/11 (64-bit)
- 4 GB RAM minimum (8 GB recommended)
- 200 MB free disk space
- Microsoft Excel or compatible spreadsheet software


INSTALLATION
------------
1. Download ClassSync_v1.0.zip.
2. Extract to a folder (e.g., C:\Program Files\ClassSync).
3. Run ClassSync.exe (no additional installation required).


QUICK START
-----------
1. Run ClassSync.exe.
2. Import data from the Data tab 
   (use "sample" folder datasets as a guide).
3. Configure optimization settings.
4. Click "Save All Data".
5. Click "Generate Schedule".
6. Monitor progress in real time.
7. Export results to Excel.

For advanced options (configuration, themes, batch processing),
see manual.txt.
