# Contributing to BNU CS Archive

Thanks for taking an interest in this repository! Please read this before opening an issue or pull request — this project is a bit different from a typical open-source codebase.

## 📌 What this repository is

This is a **personal academic archive** — a running record of one student's coursework, projects, and materials from the BS Computer Science program at Beaconhouse National University. It is not a library, framework, or product accepting feature contributions.

Because of that, **external code contributions (new features, refactors, etc.) are generally not expected or accepted.** That said, the following kinds of contributions are genuinely welcome:

## ✅ Ways you can help

- **🐛 Broken or incorrect content** — a mislabeled file, a corrupted upload, a wrong folder, or an outdated link in the README.
- **📄 Copyright / takedown requests** — if you are a rights holder (instructor, publisher, university) and would like specific material removed, please open an issue (see [Disclaimer](./README.md#-disclaimer) in the README).
- **🔐 Accidental sensitive data** — if you spot something that looks like a leaked credential, personal contact information, or other sensitive data that shouldn't be public, please report it privately (see [`SECURITY.md`](./SECURITY.md)) rather than opening a public issue.
- **💡 Suggestions** — ideas for organizing the archive better, improving the README, or documentation fixes.

## 🚫 What's out of scope

- Pull requests adding new courses, projects, or content on someone else's behalf (this archive reflects one person's actual coursework).
- Style/formatting changes to course materials, textbooks, or other third-party files.
- General open-source-style feature requests — this isn't a software project with a roadmap.

## 🗣️ How to report an issue

1. Check existing issues first to avoid duplicates.
2. Open a new issue with:
   - A clear, specific title (e.g. "Broken link in README under SM4" rather than "bug")
   - The exact file/folder path affected, if applicable
   - What you expected vs. what you found
3. For copyright or sensitive-data concerns, please be as specific as possible about the file path so it can be located and addressed quickly.

## 🙏 Code of Conduct

Be respectful and constructive. This archive represents real student work — please engage with it in the same spirit you'd want your own coursework treated.
